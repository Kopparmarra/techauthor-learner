# Install a software update package

> **WARNING:** Make sure that the radar system is in MAINTENANCE mode before you install the software package.

## Procedure

1. Connect the maintenance laptop to the service port.
2. Open the radar maintenance application.
3. Import the approved software package.
4. Verify the package signature.
5. Install the software package.
6. Verify the installed software version.

```text
$ rpu-maint package verify RPU-4.3.1.pkg
Signature: VALID
Applicability: MATCH
```

> **NOTE:** Record the installed software version in the configuration record.
